# Manuscript — Logo & Marks

The identity is a **masthead**, not a symbol: the JH monogram set between two
sienna hairline rules, reusing the ledger-rule motif so it reads as native to
the system.

## Files

| File | What | Use |
|---|---|---|
| `brandmark.svg` | JH between two sienna rules, ink initials | On paper / light surfaces. The primary mark. |
| `brandmark-inverse.svg` | Same, paper-colored | On Nightfall / dark surfaces. |
| `favicon.svg` | JH reversed inside a cedar tile, 32×32 | Browser tab, app icon, avatar. |
| `signature.svg` | Hand signature (ink) | Sign-offs, letters, the personal touch. Scale freely. |
| `social-icons.svg` | Social glyph sprite (`<symbol>` set) | `<use href="social-icons.svg#x-icon">` etc. |
| `og-card.png` | 1200×630 share card | Open Graph / Twitter card. |

## Rules

- **Clear space:** keep at least the cap-height of "JH" clear on every side.
- **Minimum size:** brandmark no smaller than ~72px wide on screen; the rules stop reading below that. The favicon tile is the small-size mark.
- **Color:** initials in ink (or paper on dark); rules always sienna. On dark, use the inverse (both paper).
- **The wordmark** is "Jake Heaps" set in Newsreader italic, paired to the mark's right with a small gap.
- **Don't:** recolor the rules to cedar, box the light brandmark, add a drop shadow, stretch, or rebuild the monogram in another typeface. The initials are Newsreader 500.
